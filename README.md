# Calculateur de dilution — GitHub Pages / PWA

Application web statique responsive, installable sur téléphone et utilisable
hors ligne après la première ouverture complète.

## Publication sur GitHub Pages

1. Copier tous les fichiers de ce dossier à la racine du dépôt.
2. Ouvrir Settings > Pages.
3. Dans Build and deployment, choisir Deploy from a branch.
4. Sélectionner la branche main et le dossier /(root).
5. Enregistrer.

Adresse attendue :
https://lucper01.github.io/Calculateur-Dilution-Android/

## Installation sur Android

1. Ouvrir le site dans Chrome.
2. Appuyer sur Installer l'application lorsqu'il apparaît, ou utiliser
   le menu Chrome > Ajouter à l'écran d'accueil.
3. Après la première ouverture complète, l'application fonctionne hors ligne.
