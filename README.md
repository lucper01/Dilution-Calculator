# Concentration and Dilution Calculator

A browser-based calculator designed to prepare direct and serial dilutions from a stock solution. The application generates a clear, tube-by-tube preparation protocol from the concentrations and final volume entered by the user.

## Main features

- Direct and serial dilution calculations
- Concentrations entered as percentages, powers of ten, scientific notation, or fractions
- Automatic calculation of source-solution and diluent volumes
- Volume units in µL, mL, and L with automatic conversion
- Detailed instructions for every dilution step
- Custom names for the stock solution, intermediate tubes, and final preparation
- Optional project, operator, lot, date, and notes fields
- Color-coded source identification and proportional source/diluent visualization
- First-use guide and quick algebraic format shortcuts
- Portfolio-style numbered navigation with active-section tracking
- Automatic coherence checks before laboratory use
- Compact protocol overview and detailed tube cards
- Protocol locking to prevent accidental parameter changes
- Step completion tracking, active-step highlighting, and progress display
- Bench view, single-step view, and laboratory full-screen mode
- Local session restoration with the current step and completed steps
- Temporary undo/redo history for parameter changes
- Automatic warning before changing a protocol that has already started
- Large critical-value display for target concentration and final volume
- Total stock, diluent, transferred volume, prepared volume, and tube count summaries
- Copy of the full protocol or an individual preparation step
- CSV and structured text exports
- Draggable result-section ordering with locally stored layout preferences
- Compact, standard, and large interface sizes
- Two-column, top-parameter, and protocol-priority desktop layouts
- Adjustable parameter-panel width
- Laboratory high-contrast mode and independent critical-value zoom
- Automatic or forced comma/dot decimal display
- Secondary unit conversion and normalized scientific concentration preview
- Smart scrolling to the next preparation step
- Sticky current-step summary and protocol minimap
- Quick actions menu and searchable command palette
- Keyboard shortcuts for common protocol actions
- Automatic input normalization and stronger focus feedback
- Local field-value copy/paste helper
- Demo mode for exploring the calculator without entering real preparation data
- French and English interface
- Light and dark themes
- Local calculation without uploading entered values

## Use

Open the calculator in a web browser:

https://lucper01.github.io/Dilution-Calculator/

Enter the target concentration, final volume, and preferred concentration format. The preparation protocol updates automatically and displays the complete sequence of dilution steps.

The calculator is intended as a preparation aid. Users remain responsible for checking the entered values, units, laboratory procedures, and compatibility of the selected volumes with their equipment.

## Privacy

Calculations, protocol progress, preferences, and session restoration are handled locally in the browser. The calculator does not require an account and does not transmit entered concentration or volume values to a remote server.
